## 제외·보류와 적용 판단

- OpenSeadragon overlays: 공식 문서와 표시 컨트롤은 읽혔지만 공개 타일이 검은 화면으로 남아 이번 신규 사진 후보에서 제외했습니다. 확대 주석 원리는 향후 유효한 데이터로 재검토할 수 있습니다.
- dSense는 현재 웹 데모를 확보하지 못했습니다. 대신 공식 LayerNavigation개념도를28번에 넣고 **문서에 남은 Windows/WPF연구 프로토타입**으로 명시했습니다. 실사용 웹 화면32개를 모두 검증했다고 주장하지 않습니다.
- Mirador 첫 원작의 일부 이미지 로딩은 실패했습니다. 로드된 Bodleian공개 자료를 별도 창으로 열고1/84·2/84페이지를 실제 확인했습니다.
- Observable system guide의 단순 반응 계산은 확인했지만 아래 다른 라이브러리 예제 오류가 있었고, 노트북 전체 실행 정상 여부는 검증하지 않았습니다.
- Sketch-n-Sketch2019아카이브는 실제 좌표 변경을 확인했지만 합성 추천 완료·최신 호환성을 검증하지 않았습니다.
- NASA궤도·지도 시간 제어·indoorfloor등은 기존 공간/평면/시간 방향과 중복이 커 최종12개에서 보류했습니다. 복잡도와 차별성을 같이 고려했습니다.
