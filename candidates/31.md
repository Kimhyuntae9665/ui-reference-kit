# 31 · 측정 점을 분류하며 보는 기술 장면

## 실제 참고 화면

![31 실제 참고 화면](../images/31-reference.png)

- 원작: OpenGeos · LiDAR Point Cloud Viewer
- [원본 출처](https://lidar-viewer.gishub.org/?url=https://s3.amazonaws.com/hobu-lidar/autzen-classified.copc.laz)
- 이미지 유형: browser_render_screenshot · 2026-10-09 보존.
- 분류: 공간
- 화면 설명: 공개 경기장 점군을 지도 위3D 점으로 표시합니다. 높이와 분류 등의 표시 기준을 바꾸고 의미 범주별 표시를 조정합니다.
- 시각 원리: 형태와 측정값·분류를 연결하는 점군 검사
- 어울리는 업무: 공간 측정·설비 현황·센서 데이터·현장 검사
- 재사용 기준: 좌표계·단위·샘플링·측정 시점과 분류 근거를 명시합니다.
- 기존 후보와의 차이: 01·03은 이해를 돕는 물체 모형입니다. 31은 측정된 점 자체가 데이터이며 색·필터가 측정 속성에 연결됩니다.
- 방법 이름: 형태와 측정값·분류를 연결하는 점군 검사
- 조작 확인: Autzen 공개 COPC 샘플이 로드되고 표시상10,653,336points를 확인했습니다. Color By를 Elevation에서Classification으로 바꾸자 범주 체크박스와 색이 바뀌었습니다. 측정 정확도는 검증하지 않았습니다.
- 참고 유형: 브라우저에서 확인한 실제 화면
- 발견 경로: MapLibre 플러그인 목록 → OpenGeos GitHub → 공개 샘플 데모
- 원본 확인 기록: Autzen 공개 COPC 샘플이 로드되고 표시상10,653,336points를 확인했습니다. Color By를 Elevation에서Classification으로 바꾸자 범주 체크박스와 색이 바뀌었습니다. 측정 정확도는 검증하지 않았습니다.

## 프로젝트 적용 시안 — 미구현

![31 적용 시안 · 미구현](../concepts/31-concept.svg)

- 적용 방향: 합성 점군을 공간 좌표와 높이 잔차로 표현해 임계값 초과 영역을 분류하는 구상입니다. 문서 대조와 별도의 기술 검사 방식 확장안입니다.
- 조작 아이디어: 영역을 선택하고 기준면과 임계값을 바꾸며 각 점의 측정값과 분류 근거를 확인하는 조작을 구상합니다.
- 선택 시 고려할 점: GPU·대용량 스트리밍·좌표 보정 부담이 큽니다. 실제 공간 데이터가 없는 문서 업무에 억지로 적용하지 않습니다.

이 SVG는 합성 업무 예시를 비교하기 위한 구성 시안입니다. 실제 조작·계산이 가능한 구현 화면으로 인용하지 않습니다. 현재 구현 상태는 [DECISIONS.md](../DECISIONS.md)를 확인하세요.
