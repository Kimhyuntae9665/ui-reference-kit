# 24 · 입력·코드·결과가 이어지는 계산 노트

## 실제 참고 화면

![24 실제 참고 화면](../images/24-reference.png)

- 원작: Observable Notebooks 2.0 · System guide
- [원본 출처](https://observablehq.github.io/notebook-kit/system-guide)
- 이미지 유형: browser_render_screenshot · 2026-10-09 보존.
- 분류: 설명
- 화면 설명: 설명 다음에 입력 슬라이더, 해당 입력의 코드, 계산 결과 셀이 이어집니다. 입력을 바꾸면 참조하는 결과 셀이 다시 계산됩니다.
- 시각 원리: 계산 과정과 결과를 함께 공개하는 반응형 셀
- 어울리는 업무: 업무 규칙 검토·재현 가능한 실험·분석 설명
- 재사용 기준: 실제 계산식·의존 입력·오류를 보여주고 편집 권한과 읽기 권한을 분리합니다.
- 기존 후보와의 차이: 20은 서사와 조작 설명을 결합합니다. 24는 셀 간 변수 의존과 재계산을 드러내므로 계산의 재현·검토에 더 적합합니다.
- 방법 이름: 계산 과정과 결과를 함께 공개하는 반응형 셀
- 조작 확인: x 입력을 50에서70으로 바꾸자 x² 결과가2500에서4900으로 바뀌었습니다. 가이드 아래 일부 별도 라이브러리 예제 오류도 있어 전체 노트북 정상 동작을 주장하지 않습니다.
- 참고 유형: 브라우저에서 확인한 실제 화면
- 발견 경로: Hacker News의 브라우저 노트북 논의 → Observable 공식 Notebook Kit
- 원본 확인 기록: x 입력을 50에서70으로 바꾸자 x² 결과가2500에서4900으로 바뀌었습니다. 가이드 아래 일부 별도 라이브러리 예제 오류도 있어 전체 노트북 정상 동작을 주장하지 않습니다.

## 프로젝트 적용 시안 — 미구현

![24 적용 시안 · 미구현](../concepts/24-concept.svg)

- 적용 방향: 발주·입고·청구 비교식을 입력 셀, 코드 셀, 결과 셀로 분리합니다. 계산이 어떤 값에 의존하는지 검토하는 구상입니다.
- 조작 아이디어: 입력 셀의 값을 바꾸면 해당 값을 참조하는 계산과 출력만 다시 실행하는 조작을 구상합니다.
- 선택 시 고려할 점: 코드가 중심이 되면 일반 사용자에게 복잡합니다. 핵심 입력과 결과만 먼저 보여주는 접기 구조가 필요합니다.

이 SVG는 합성 업무 예시를 비교하기 위한 구성 시안입니다. 실제 조작·계산이 가능한 구현 화면으로 인용하지 않습니다. 현재 구현 상태는 [DECISIONS.md](../DECISIONS.md)를 확인하세요.
