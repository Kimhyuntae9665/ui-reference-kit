# 22 · 조건을 동시에 좁히는 다축 비교

## 실제 참고 화면

![22 실제 참고 화면](../images/22-reference.png)

- 원작: Vega · Interactive Parallel Coordinates
- [원본 출처](https://vega.github.io/vega/examples/parallel-coordinates-interactive/)
- 이미지 유형: browser_render_screenshot · 2026-10-09 보존.
- 분류: 비교
- 화면 설명: 차량 한 대가 여러 세로 축을 잇는 선으로 나타납니다. 한 축에서 범위를 선택하면 조건에 맞는 선이 강조되고 다른 선은 흐려집니다.
- 시각 원리: 여러 속성을 한 화면에서 범위 선택으로 비교
- 어울리는 업무: 대안 탐색·운영 조건 비교·다변량 이상치
- 재사용 기준: 축별 단위·방향을 명시하고 선택 범위·선택 건수·초기화를 제공합니다.
- 기존 후보와의 차이: 10의 신호 트랙은 시간 변화입니다. 22의 축은 비용·품질·지연 같은 서로 다른 속성이며 한 선은 하나의 대안입니다.
- 방법 이름: 여러 속성을 한 화면에서 범위 선택으로 비교
- 조작 확인: Cylinders 축에서 범위를 드래그해 강조 대상이 바뀌는 것을 확인했습니다. 축 재배열·더블클릭 초기화는 공식 안내에서 확인했습니다.
- 참고 유형: 브라우저에서 확인한 실제 화면
- 발견 경로: 해외 데이터 시각화 탐색 → Vega 공식 예제
- 원본 확인 기록: Cylinders 축에서 범위를 드래그해 강조 대상이 바뀌는 것을 확인했습니다. 축 재배열·더블클릭 초기화는 공식 안내에서 확인했습니다.

## 프로젝트 적용 시안 — 미구현

![22 적용 시안 · 미구현](../concepts/22-concept.svg)

- 적용 방향: 입고율·수량차·단가차·경과일·근거 수를 나란한 축으로 펼쳐 예외 문서를 비교하는 구상입니다.
- 조작 아이디어: 축 위 범위를 드래그해 브러시를 만들고 여러 범위를 AND 조건으로 조합하는 조작을 구상합니다. 예시는 5건 중 2건을 강조합니다.
- 선택 시 고려할 점: 데이터가 많으면 선이 겹칩니다. 대표 표본·투명도·선택 집계가 필요하며 인과관계를 입증하지 않습니다.

이 SVG는 합성 업무 예시를 비교하기 위한 구성 시안입니다. 실제 조작·계산이 가능한 구현 화면으로 인용하지 않습니다. 현재 구현 상태는 [DECISIONS.md](../DECISIONS.md)를 확인하세요.
