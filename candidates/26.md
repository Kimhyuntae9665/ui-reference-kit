# 26 · 명령으로 들어가는 중첩 탐색

## 실제 참고 화면

![26 실제 참고 화면](../images/26-reference.png)

- 원작: Cmd+kit · Command palette demo
- [원본 출처](https://cmd-kit.vercel.app/)
- 이미지 유형: browser_render_screenshot · 2026-10-09 보존.
- 분류: 탐색
- 화면 설명: 검색창 아래 동작과 단축키가 목록으로 나타납니다. Documentation을 고르면 경로가 바뀌고 하위 명령이 보입니다.
- 시각 원리: 페이지 위치보다 수행할 동작을 먼저 찾는 탐색
- 어울리는 업무: 숙련 사용자 도구·다수 명령·빠른 대상 접근
- 재사용 기준: 검색 없이도 기본 명령을 발견할 수 있게 하고 실행 전 대상·범위를 확인합니다.
- 기존 후보와의 차이: 기존20개에는 실행 구조·내용 시각화가 많습니다. 26은 행동을 검색해 진입하는 별도 탐색 방식으로 주 화면을 보조합니다.
- 방법 이름: 페이지 위치보다 수행할 동작을 먼저 찾는 탐색
- 조작 확인: Documentation 하위 명령을 열고 React를 입력해 검색 결과 순서가 바뀌는 것을 확인했습니다. 실제 명령의 외부 실행은 하지 않았습니다.
- 참고 유형: 브라우저에서 확인한 실제 화면
- 발견 경로: 개발자 도구·명령 팔레트 조사 → 프로젝트 공식 데모
- 원본 확인 기록: Documentation 하위 명령을 열고 React를 입력해 검색 결과 순서가 바뀌는 것을 확인했습니다. 실제 명령의 외부 실행은 하지 않았습니다.

## 프로젝트 적용 시안 — 미구현

![26 적용 시안 · 미구현](../concepts/26-concept.svg)

- 적용 방향: 문서 검토 중 ‘차이를 설명하기’ 같은 행동부터 선택한 뒤 분할 입고 확인이나 가격 변경 근거 찾기로 들어가는 구상입니다.
- 조작 아이디어: 명령 검색, 키보드 선택, 하위 명령 열기, Esc로 한 단계 돌아가기 조작을 구상합니다.
- 선택 시 고려할 점: 검색할 명칭을 모르면 막힙니다. 초보 사용자 온보딩이나 공간·흐름을 설명하는 첫 화면의 대체재로는 약합니다.

이 SVG는 합성 업무 예시를 비교하기 위한 구성 시안입니다. 실제 조작·계산이 가능한 구현 화면으로 인용하지 않습니다. 현재 구현 상태는 [DECISIONS.md](../DECISIONS.md)를 확인하세요.
