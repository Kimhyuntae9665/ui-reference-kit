# 21 · 면적에서 시작하는 계층 확대

## 실제 참고 화면

![21 실제 참고 화면](../images/21-reference.png)

- 원작: D3 · Zoomable treemap
- [원본 출처](https://observablehq.com/@d3/zoomable-treemap)
- 이미지 유형: browser_render_screenshot · 2026-10-09 보존.
- 분류: 계층
- 화면 설명: 큰 사각형 안에 하위 집단을 면적으로 배치하고, 선택한 집단으로 화면 전체를 확대합니다. 상단 경로가 현재 계층을 알려줍니다.
- 시각 원리: 집단의 크기와 포함 관계를 동시에 읽는 계층 탐색
- 어울리는 업무: 업무 묶음·비용 구성·오류 유형의 드릴다운
- 재사용 기준: 면적은 하나의 양적 척도에만 연결하고 현재 경로·상위로 돌아가기를 표시합니다.
- 기존 후보와의 차이: 13 Sankey는 이동량, 14 관계 지도는 연결을 보여줍니다. 21은 부모·자식 포함 관계와 집단 크기를 확대하며 탐색합니다.
- 방법 이름: 집단의 크기와 포함 관계를 동시에 읽는 계층 탐색
- 조작 확인: vis를 클릭해 operator·data·controls 등 하위 집단으로 바뀌는 것을 확인했습니다.
- 참고 유형: 브라우저에서 확인한 실제 화면
- 발견 경로: Observable 공식 D3 계층 갤러리 → 원작 데모
- 원본 확인 기록: vis를 클릭해 operator·data·controls 등 하위 집단으로 바뀌는 것을 확인했습니다.

## 프로젝트 적용 시안 — 미구현

![21 적용 시안 · 미구현](../concepts/21-concept.svg)

- 적용 방향: 합성 검토금액을 공급사와 발주별 면적으로 나눕니다. Matchroom 문서 묶음에서 큰 검토 대상을 먼저 찾는 구상입니다.
- 조작 아이디어: 영역을 선택해 하위 계층으로 확대하고 상단 경로로 돌아가는 조작을 구상합니다. 정적 시안에서는 확대 대상만 표시했습니다.
- 선택 시 고려할 점: 작은 면적의 라벨은 읽기 어렵습니다. 면적이 작은 항목을 찾을 검색·목록 보조가 필요합니다.

이 SVG는 합성 업무 예시를 비교하기 위한 구성 시안입니다. 실제 조작·계산이 가능한 구현 화면으로 인용하지 않습니다. 현재 구현 상태는 [DECISIONS.md](../DECISIONS.md)를 확인하세요.
